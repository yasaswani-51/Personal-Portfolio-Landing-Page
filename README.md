# Personal Portfolio Landing Page

A responsive one-page portfolio for Doki Yasaswani, built with semantic HTML5, CSS Flexbox and Grid.

**Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

## Structure

- `index.html` - page content (header/nav, main sections, footer)
- `style.css` - styles and the mobile media query
- `images/` - avatar and project illustrations (all with alt text)

## Run locally

Open the folder in VS Code and start the Live Server extension.

## Design decision

A blinking LED dot in the hero echoes the Arduino emergency device project and uses one signal colour as the only accent against a navy and off-white palette.
