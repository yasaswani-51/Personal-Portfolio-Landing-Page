Projects

  • Arduino Emergency Assistive Device

    Embedded systems, September 2026

    A low-cost local emergency alert built on an Arduino UNO with a push button, potentiometer, LED, buzzer and servo motor.

    Hold the button for the selected time and the LED flashes, the buzzer sounds and the servo lifts a HELP flag to 90 degrees. The potentiometer sets the hold time between 1 and 5 seconds, and a short press is ignored to prevent accidental alerts.

    View code on GitHub

  • Emergency Route Optimization System

    Python, September 2026

    A Python application that finds efficient routes for emergency vehicles using Dijkstra's algorithm and priority queues.

    It accounts for traffic conditions, skips blocked roads and calculates alternative routes. The interface is built with Tkinter.
